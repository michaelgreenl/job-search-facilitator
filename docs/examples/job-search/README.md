# Job Search Automation

This directory is the public template for the scheduled job-search task.

Read these files in the order declared by `automation.md`:

- `user-info.md`: private applicant facts and preferences.
- `post-evaluation.md`: evidence, rejection, and recommendation rules.
- `strategy.md`: discovery scope and ranking policy.
- `navigation.md`: startup, browser, coverage, and safety rules.
- `reporting.md`: report rendering and application sync.
- `automation.md`: the prompt saved in ChatGPT.

Copy every file to `docs/agents/job-search`. Edit only the private copy.
