# Application and Outreach Update Check

This directory is the public template for the application tracker automation.

The task reads active tracking context from the local API. It checks Gmail and LinkedIn for relevant updates.

The application owns tracking data. ChatGPT owns browser checks, scheduling, and task history.

Files:

- `evidence-policy.md`: status, matching, ambiguity, and event identity rules.
- `integration.md`: startup, API, browser, safety, and verification rules.
- `automation.md`: the prompt saved in ChatGPT.

Copy every file to `docs/agents/update-check`. Edit only the private copy.
